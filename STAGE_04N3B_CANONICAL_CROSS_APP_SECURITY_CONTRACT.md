- **`isAdmin()`:** Single-document `get`/write helper: `isVerifiedAdminToken() || (isNonAnonymousUser() && 'email_verified' in request.auth.token && request.auth.token.email_verified == true && exists(/databases/$(database)/documents/admins/$(request.auth.uid)))`. *(Never allowed inside unconstrained collection `list` rules.)*
